## Code navigation

This session's code tools are bound to the current directory, the worktree you work in. For a question about code symbols (where a function is defined, what calls it, what a file contains), use the Serena tools first: load them with ToolSearch (select:mcp__serena__find_symbol,mcp__serena__find_referencing_symbols,mcp__serena__get_symbols_overview), then call find_symbol, find_referencing_symbols and get_symbols_overview. Use rg or the Grep tool for text that is not a symbol. Do not read whole files to find a definition.
