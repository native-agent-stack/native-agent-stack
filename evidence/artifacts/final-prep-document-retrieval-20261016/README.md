## Masking and independent reproduction

`mask_capture.py` reuses `scripts/host_receipts.py:273` for privacy sanitization and adds explicit `<SCRATCH>`/`<REPO>` placeholders, ANSI terminal-control removal, CR-to-LF normalization, and a context-specific `<CONTAINER_ID>` for the creation capture. It retains every output line, command and exit status. It does not manufacture a passing run. The test file contains synthetic strings only; its behavioral regression failed on an unhandled native progress-control sequence before the fix and passed afterward (`captures/mask-regression-before.masked.log:2`, `captures/mask-regression-after.masked.log:2`).

For each published capture, the private original has the same basename with `.raw.log` in place of `.masked.log`. The co-op has the private capture directory. Raw originals and their checksums stay private and are referenced by name only. `capture-index.json` hashes **published bytes only** and gives command/result line references. The reproduction command is:

```sh
python3 mask_capture.py --input '<PRIVATE_RAW_CAPTURE>' --output '<PUBLISHED_CAPTURE>' \
  --scratch '<PRIVATE_SCRATCH_ROOT>' --repository '<PRIVATE_CHECKOUT_ROOT>'
# Add --container-create only for poppler-container-create.raw.log.
```

The angle draft and this narrative are interpretations of the cited sources; neither is a measured-output substitute. The separate representative-corpus proposal retains unresolved model/harness inputs as named gaps before any run.
