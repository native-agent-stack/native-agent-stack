# Capture integrity

The admissible native captures in this preparation are the 18 files under
`captures/`, indexed by `masked-captures.json`. They were recorded by the
installed util-linux `script` command, whose version is captured in
[recorder-version.typescript](captures/recorder-version.typescript). The recorder
writes the exact command in its first line and `COMMAND_EXIT_CODE` in its final
line. Those native fields supply every command and return-code locator in the
index; they are not reconstructed from a driver summary.

The raw transcripts stay private, identified by basename only in the manifest.
Their private directory was supplied to the co-op for reproduction. Only hashes
of the published masked bytes appear in the repository.

`mask_capture.py` removes ANSI SGR sequences and substitutes the explicitly
supplied scratch prefix with `<scratch>` and private host-home prefix with
`<host-home>`. It preserves all remaining bytes, including CRLF, errors, blank
lines, trailing whitespace, command syntax and exit codes. The private prefix
values are not embedded in the script. Commands therefore carry marked
placeholders. A plain output file without a native recorder header/footer is
never given an inferred return code.

`test_mask_capture.py` contains seven synthetic unit controls for this publication
transform. They test byte preservation, failure-code preservation, missing-footer
handling, placeholder validation, idempotence, and published-byte hash custody.
They are not candidate E2E evidence. The invocation is:

```text
python3 -B -m unittest -v test_mask_capture
```

The native transcript is a PTY recording: stdout and stderr are combined and
terminal line endings are retained. It is not represented as two independent
streams. Each output hash binds that complete masked transcript, including native
header/footer. The recorder's own source manual states that `--return` returns
the child's status and stores it in the typescript. This behavior was additionally
exercised by the intentional RTK exit-7 control.

An earlier local draft retained bare native stdout files and a selected-lines
installation summary without a retained exact command/return-code envelope.
That draft is withdrawn from this publication. Fresh captures replace it; the old
private files remain audit material and are not used to fill a missing receipt.
The current `execution-receipt.json` and `invoke-evidence.json` are indexes to
the native captures, not substitute outputs.

All fixture, upstream unit-test and seeded-corpus runs are labelled **SIMULATION**
in the records. Native execution of these inputs does not establish live-session
adoption, model answer quality, provider savings or billing. The ccusage cost
comes from the published fixture. Host `--version` probes are separately
captured and are never substituted by scratch version probes.

The co-op's independent private reproduction passed on 2026-10-16. The private
record “MASKED-REPRO CHECK PASS foundation/token-efficiency, 2026-10-16” reports:
18/18 captures regenerated byte-identical; published hashes and byte counts,
native command headers, and return-code footer/line locators all matched;
31/31 evidence-ledger entries matched; seven masker tests passed; the private
locator scan found zero hits. Capture, masker and test bytes were unchanged for
that check. The co-op will re-verify the committed bytes after PR opening.
A missing current production-use window and macOS execution remain named gaps.

The bundle's [.gitattributes](.gitattributes) disables Git text normalization for
`captures/*.typescript`. The repository-wide `text=auto eol=lf` rule would otherwise
change the PTY CRLF bytes while staging. This scoped rule preserves the reviewed
derivatives without changing them; staged blob hashes are checked against the
published manifest before commit.
