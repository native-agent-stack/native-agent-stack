Differential measurement of the front matter pipeline of scripts/adoption_status.py (agent_front_matter, then agent_names: Bun.YAML.parse) against the installed Claude Code client, 2026-10-13.

What is measured. The client is asked: each text of a generated corpus is written as .claude/agents/fNNNNN.md of a scratch project, with its own name token (zz00000-..., standing in for the prefix `stack-` of the name
so that the token survives every spelling that breaks the literal: an escape, a fold over two lines), the installed client is started in headless mode (`claude -p ok --output-format stream-json --verbose --max-turns 1
--no-session-persistence --model haiku`, in the scratch project, 400 files a start) and killed as soon as its init record has been read, and the agents listed in that record are the agents the loader served: a name that
holds a text's token tells which text it came from. That is the client's own loader, parser and engine (its embedded Bun), not a copy of them. The pipeline is then run on the same texts. The property asserted is one-sided:
wherever the client served a name, the pipeline returns that name or says it cannot tell (the parse throws), never none and never another name (a MISS). Where the client served nothing (no description, an invalid
name, a text that fails both of its parse attempts) a name from the pipeline is an over-report, the safe direction, and an unreadable is counted apart.

The corpus (16,428 texts; the drivers are the author's private record, and tests/fixtures/agent_frontmatter/client-oracle.json is the committed subset of 2,987 texts with the client's answers, which
tests/test_adoption_status.py RealBunTests replays): the spellings of the key and of the value (quoted, block scalars, escapes, anchors, tags, flow collections, folds), openers and closers, neighbouring keys,
CRLF and lone CR, a byte order mark, comment and blank lines between a key and its value and around block scalars at indentations 0 to 4 (the families `comments` and `comments-last`, added after the command center's
P1 of 2026-10-13), and a seeded fuzz (4,000 texts, seed 20261013) of realistic front matter with insertions, deletions, swaps, indentation changes, comment lines and blank lines.
