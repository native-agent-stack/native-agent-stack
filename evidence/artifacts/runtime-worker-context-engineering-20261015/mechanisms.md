## Muse, documentation only through the existing fence

| Need | Vendor documentation and fence consequence |
| --- | --- |
| Auto/manual compaction | Auto when context fills; `/compact` creates a lossy model-visible summary, retains scrollback, and manual use does not consume the auto-compaction budget. Numeric threshold, budget count and exact summary schema at 1.4.7 are not established. `/recap` is display-only and does not free context. [Meta interactive, Control the context](https://dev.meta.ai/docs/muse-code/interactive#context), read 2026-10-15. |

The directory-grants amendment admits only its reviewed inventory. It does not grant the host home, shared memory stores or context plugins. A reader cannot maintain files merely because a native memory feature exists: retain its proposed handoff in allowed output and let the owning writer update the lead. This research never calls Muse or its launcher.
