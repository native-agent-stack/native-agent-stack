To sign up for a Muse Code subscription, you will need a Meta Account. Using your Meta Account, you can create an associated Meta Model API account and sign up for a subscription. The subscription applies to the Muse Code API key that is automatically connected in the Muse Code CLI onboarding process. This credential is for use with Muse Code only. Any additional API keys you create under your Meta Model API account will be billed through pay-as-you-go.
