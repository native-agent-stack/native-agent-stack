## Smoke procedure and fixed decision rule

Run one bounded isolated-builder smoke per profile, sequential initially so
provider capacity is not confused with compatibility. Each deadline is900s;
no retry/alternative model is allowed to erase the first attempt. Failures are
retained. A later changed-mechanism retry gets a separate receipt and reason.
Fresh worktree must differ from the other lanes and initial checkout.

The brief requests only a public synthetic task in that worktree: use native
read to inspect a public fixture, write a small deterministic result, run its
specified local check, load a named canonical skill and complete one named
Context Mode computation. No broker, account, order, credential read or provider
configuration work. Never send a key through a brief, profile or lane.

PASS requires all of:

1. Exact native runtime pin and explicit requested model/route recorded.
2. Runtime completes normally within deadline, no error/refusal terminal.
3. Deterministic result exists in its assigned workspace and its check passes.
4. Native completed tool events demonstrate the requested read/write/check and
   the admitted skill/Context Mode calls; configured presence alone is not invoke.
5. Private profile state and unique worktree attribution are evidenced; existing
   role restrictions remain covered by model-free configuration tests.
6. The runtime/gateway-reported model ID is recorded per job, separately from
   requested ID. Normalized/echoed IDs are labelled as such; no upstream wire
   identity, actual reasoning level or invoice verification is invented.

Pi custom reasoning config requests max with the supported thinkingLevelMap;
other harnesses use their highest supported configured setting, recorded
literally. Gateway transformations or normalized model fields remain observed
limitations. Unknown native price metadata stays unpriced, not measured $0.

No web discovery before profile PASS. A qualified profile may subsequently use
its own admitted web tools on non-gate work; their presence does not qualify
every external MCP/server or a role's denied tools. Native Muse continues to
disable its web tools and contributor mode under the separate item3 decision.
