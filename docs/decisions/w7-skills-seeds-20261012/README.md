## Owner handoff and readiness

cc-native-practice owns the Tier 1 defaults, Tier 2 index, vendor installer and
paired measurements; the runtime-profile lane owns wiring and acceptance.
Tier 1 remains one evidenced default per lifecycle slot. Tier 2 uses the full
source index on demand, with a pinned skill installed only in the owned run
scope by the supported vendor route and its usage counted by the invoke tracker.

promote the skill.

implementation, role and pin. A seed already present in a catalog is not

correct-skill invocation, task outcome and complete provider tokens/cost. No
whole-pack installation or replacement research harness is introduced.
