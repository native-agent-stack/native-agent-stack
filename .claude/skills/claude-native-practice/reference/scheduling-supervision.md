## scheduled-tasks

- **Route:** Session `/loop` and the Cron tools only for temporary in-session polling (7-day expiry, no catch-up); a session resumed with `--resume` or `--continue` gets back its CronCreate tasks that have not expired or passed, and a backgrounded session keeps them firing, so those paths run CronList first and cancel stale tasks with CronDelete; GitHub Actions schedules repository jobs (Claude runs inside GitHub are retired, 2026-10-10, so a scheduled Claude task runs locally: see github-action)
