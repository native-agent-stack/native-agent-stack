## headless-sdk

**Status:** default (scoped). **Default:** `claude -p` with every fence on the command line

- **Route:** An explicit `--permission-mode dontAsk` with an explicit `--allowedTools` list for unattended workers (never inherit: an inheriting `-p` run on this host starts in bypassPermissions); `--strict-mcp-config` with `--mcp-config`; `--setting-sources` or `--restricted` (then carry the deny list and guard hooks through `--settings`, or keep code-running tools out of `--tools`); `--tools`, `--max-turns` (documented in cli-reference, absent from `--help`), `--max-budget-usd`, `--json-schema`; bound the post-final-turn wait with `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS`; `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` for child processes; the Claude Agent SDK (Python) as the measured reader and extraction worker
- **Alternatives, ranked:** 1. claude-agent-sdk-python for hosted workers; 2. claude-agent-sdk-typescript
- **Rejected:** `--bare` on OAuth subscription lanes (it never reads OAuth); `--bare` for reader jobs (it drops Glob and Grep; measured on 2.1.295); Relying on the built-in starting mode
- **Evidence:** headless.md; headless-sdk-O2, O3, O4, O5, O12; Measured: --bare leaves only Read of Read/Glob/Grep (client-behaviour-2.1.295 record)
- **Notes:** HOST-07 required `--bare` outside trusted checkouts; on this OAuth host the documented fence is `--restricted` with `--permission-prompts none` and `--strict-mcp-config`. Two call sites lack fences (skill_usage.py). Gap ledger of 2026-10-15 (docs read 2026-10-15T10:34Z for client 2.1.300). Background commands (B2-0002, B4-0001): in a `-p`, Agent SDK, CI or cloud session a background Bash or PowerShell command stops at a time limit counted from when it enters the background (tools-reference.md:192, :196; since 2.1.285, and in unattended sessions only since 2.1.288: tools-reference.md:194, anthropics/claude-code@94506ff0 CHANGELOG.md:1280 and :978): 30 minutes, or the `timeout` passed with `run_in_background` up to 2 hours (:198-199), and 10 minutes in a `-p` run whose prompt is text rather than `--input-format stream-json` (:201). `BASH_DEFAULT_TIMEOUT_MS` above 1800000 (above 600000 in a text-prompt `-p` run) and `BASH_MAX_TIMEOUT_MS` above 7200000 raise these, and a lower value never shortens them (:207-210); prefer a per-command `timeout`, because a higher `BASH_DEFAULT_TIMEOUT_MS` also lengthens every foreground command (env-vars.md:191). The limit is not `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS`, which bounds idle waiting after the final turn; a running background command the main conversation started holds the run open until it exits or reaches this limit (env-vars.md:366; tools-reference.md:188). The template's `BASH_MAX_TIMEOUT_MS` 1800000 leaves the 2-hour maximum (adoption/templates/claude.settings.template.json:29). Retry (C1-0001): an unattended worker that makes model requests runs with `CLAUDE_CODE_RETRY_WATCHDOG=1` and a bounded `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` (env-vars.md:379-380; the cap needs 2.1.295, CHANGELOG.md:384): each request waits out 429 and 529 errors up to the cap, and a 429 for a spend limit or exhausted credits still fails at once. The review worker sets both, the cap at 900000 ms, a third of its 2700 s run timeout (tools/claude-review-worker/worker.py, SANDBOX_ENV). Left unset: skill_usage.py's `/skill-doctor` (a local command, $0 and 0 turns), observability/claude_usage_sampler.py and tools/token-e2e/freeze_snapshot.py (capacity probes, where a 429 is the reading), examples/claude-runtime-sdk (an example routed through the OmniRoute gateway) and blueprints/us-equities/research-runtime/run_worker.py (runtime selections stay with the trading lane, blueprints/us-equities/AGENTS.md:9); the ns-run profiles run pi and OpenCode, not Claude Code. Messages (B4-0002): `dontAsk`, `acceptEdits` and `auto` count as prompting, so a `-p` worker holds a message from a session that bypasses permission prompts, cannot show the approval dialog, and drops it after `dialogExpiry`, five minutes by default (cross-session-messaging.md:203, :205, :224, :227); `--restricted` loads only managed settings and `--settings` (cli-reference.md:125), and `--setting-sources` without `user` skips the user-settings accept (cli-reference.md:129). A fenced `-p` worker that must take messages starts with `{"crossSessionInbound":"accept"}` in its `--settings` (cross-session-messaging.md:231). No launcher in this repository takes messages: the review worker is one-shot and `--restricted` with no accept, on purpose, and the probes run one prompt and exit; the 2026-10-13 overnight MCP paper agent, launched from outside this repository, does take them and already passes the accept. SDK client (B1-0006): the Python Agent SDK runs the CLI bundled in its package unless `cli_path` names another (anthropics/claude-agent-sdk-python@c10b52c6 README.md:15-18; agent-sdk/python.md:891). 0.2.167 bundles 2.1.300 and 0.2.163 bundled 2.1.286 (CHANGELOG.md:3-7, :40-44), below the 2.1.295 floor for `onFailure` guard hooks (anthropics/claude-code@94506ff0 CHANGELOG.md:369-371), so adoption/new-wsl-profile.json now pins 0.2.167.
